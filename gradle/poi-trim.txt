# Parts of Apache POI left out of the mod jar (read by every build.*.gradle.kts).
# The mod only reads and writes .xlsx (and .csv), so the Word, PowerPoint and
# Visio parts and digital signatures are dead weight (about 4 MB of the jar).
#
# One folder per line, as a path inside the jars. Each folder is removed together
# with xmlbeans' name index for it (org/apache/poi/schemas/ooxml/javaname/<folder>).
#
# Keep org/apache/poi/xwpf (Word): POIXMLDocumentPart.read uses XWPFRelation
# while opening ANY workbook, and that class links the other XWPF classes.
# Without the Word schemas below those still load fine; only Word files need them.
#
# Tested 2026-11-08 by opening, reading, recalculating, saving and reopening
# Excel-made workbooks, the mod's own and hub workbooks, and a generated one with
# comments, a picture, a chart, a table, an autofilter and conditional formatting:
# same results as the full libraries. Re-test like that before adding to this list.

# POI code for PowerPoint, Visio and signatures
org/apache/poi/xslf
org/apache/poi/xdgf
org/apache/poi/poifs/crypt/dsig

# equations, bibliographies and signatures
